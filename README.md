* PySpark MLlib
* Matplotlib
* Google Colab

## Key Features

* Data preprocessing
* Feature selection
* Flight delay prediction
* Logistic Regression model
* Prediction visualization

## Machine Learning Workflow

* Data Cleaning
* String Indexing
* Feature Vector Creation
* Train-Test Split
* Model Training
* Prediction
* Model Evaluation

## Results

* Successfully predicted flight delays
* Generated prediction insights
* Demonstrated scalable machine learning using PySpark

This project demonstrates predictive analysis on airline flight data using PySpark MLlib and machine learning techniques.
